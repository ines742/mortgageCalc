# My Mortgage Calculator

## Introduction
My Mortgage Calculator is a simple, responsive web app for estimating mortgage payments and understanding how principal, interest, and term affect monthly costs. It’s built with Next.js and Tailwind CSS for a fast, modern UI.

## Technologies / Tech Stack
- Next.js 14
- React 18
- TypeScript 5
- Tailwind CSS
- PostCSS
- ESLint

## Features
- Clean, responsive UI
- Fast client-side interactivity
- Built with the Next.js App Router

## Development Process
1. Install dependencies.
2. Run the development server.
3. Edit UI in the App Router pages (for example: app/page.tsx).
4. Hot reload reflects changes instantly.

## Running the Project (Development)
From the project root:
```bash
npm install
npm run dev
```
Open http://localhost:3000 in your browser.

## Build and Start (Production)
```bash
npm run build
npm run start
```

## Environment Variables
None required for the default setup.
